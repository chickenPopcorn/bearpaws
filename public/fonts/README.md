# Fonts used by Cadence

These fonts are served locally with the app and do not require an external font service.

- **Libre Baskerville** — the song title and score annotations. Original variable TrueType font from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/librebaskerville), under the SIL Open Font License in `libre-baskerville-OFL.txt`.
  - Source: `https://raw.githubusercontent.com/google/fonts/main/ofl/librebaskerville/LibreBaskerville%5Bwght%5D.ttf`
  - SHA-256: `05a95421961341c5b2556285e8415df9db27dab4f4abe22b446b3c6a8b916c5d`
- **Bravura** — the clefs, time signatures, and accidentals. Unmodified WOFF2 font from [Steinberg](https://github.com/steinbergmedia/bravura), under the SIL Open Font License in `bravura-OFL.txt`.
  - Source: `https://raw.githubusercontent.com/steinbergmedia/bravura/master/redist/woff/Bravura.woff2`
  - SHA-256: `e68df66446e3ffa6f474ce9eb2949e938102406f12d8f40ad8754398c50f55d4`
- **Cinzel Decorative** — the larger initial in the song title. Unmodified regular TrueType font from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/cinzeldecorative), under the SIL Open Font License in `cinzel-decorative-OFL.txt`.
  - Source: `https://raw.githubusercontent.com/google/fonts/main/ofl/cinzeldecorative/CinzelDecorative-Regular.ttf`
  - SHA-256: `5b862be329103ad287a10f0a53e27a40e8cc519999253f1a0223e2dc330b10b8`

Downloaded on October 16, 2026. Musical glyphs use SMuFL code points and registration: a 40-unit font size corresponds to the score's 10-unit staff spacing.
